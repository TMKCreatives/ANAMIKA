# Anamika the Chat Bot — free website starter

This is a free, open-source static website starter for a warm, one-question-at-a-time friendship-style chat.

## Important limitation
This version is a **guided demo**, not a live AI chatbot. It responds with a prepared sequence of supportive prompts. To make it respond naturally to any message like ChatGPT, you need to connect a model through a server-side backend. Never put an API key in `index.html` or any public repository.

## Publish it free with GitHub Pages
1. Sign in or create a GitHub account.
2. Create a new **public** repository, for example `anamika-chatbot`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish it. GitHub will show a public URL like `https://YOUR-USERNAME.github.io/anamika-chatbot/`.

The exact URL depends on your GitHub username and repository, so it cannot be created until you publish it.
